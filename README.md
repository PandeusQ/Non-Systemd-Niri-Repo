# Non-Systemd Niri Dotfiles

My personal dotfiles optimized for a lightweight, non-systemd Linux environment centered around the **Niri** scrollable-tiling Wayland compositor.

## 🛠️ Included Configurations
| Component | Software |
| --- | --- |
| Terminal | Alacritty |
| Status Bar | Waybar |
| Launcher | Wofi |
| Color Scheme | Matugen |
| Wallpaper | Awww |

## ⌨️ Keybindings

| Shortcuts | Action |
| --- | --- |
| `Mod + Q` | Open terminal |
| `Mod + W` | Launcher (wofi toggle) |
| `Mod + B` | Firefox |
| `Mod + E` | File manager (nemo) |
| `Mod + T` | Telegram |
| `Mod + Tab` | Overview |
| `Mod + C` | Close window |
| `Mod + F` | Maximize |
| `Mod + V` | Floating mode |
| `Print` | Screenshot |
| `F12` | Color picker |

| Shortcuts | Action |
| --- | --- |
| `Mod + H/J/K/L` | Move focus |
| `Mod + ← ↑ ↓ →` | Move focus |
| `Mod + Ctrl + H/J/K/L` | Move window |
| `Mod + Shift + H/J/K/L` | Monitors |

## 🧱 Workspaces

| Shortcuts | Action |
| --- | --- |
| `Mod + 1..9` | Switch workspace |
| `Mod + Shift + 1..9` | Move window to workspace |
| `Mod + U / I` | Workspace up / down |

## 🎨 Overview

Wallpapers are managed via the **awww** Wayland daemon, while colors and themes across all applications are dynamically generated using **Matugen** to maintain a unified aesthetic.
